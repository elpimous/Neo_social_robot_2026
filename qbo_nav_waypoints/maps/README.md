# Carte

Par défaut, le launch utilise la carte de `qbo_navigation` (`map/map.yaml`).
Pour une autre carte : copie-la ici et passe `map:=` au lancement.

Conseil centrage portes : chaque ouverture doit apparaître blanche (libre)
entre deux montants noirs nets, sans pixels gris (inconnus). Retouche le `.pgm`
dans GIMP si besoin.
